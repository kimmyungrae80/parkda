# 인증 전환과 기존 데이터 매핑 (정책 초안)

## 원칙
- 기존 데이터는 **이름·전화번호만으로 같은 사람으로 자동 연결하지 않는다.** 동명이인, 번호 변경, 공용 기기 문제가 있다.
- 기존 기기 데이터(localStorage 의 `pd_user`, `pd_matches`)는 로그인 후에도 그대로 남고, 서버로 옮기려면 사용자 동의가 필요하다.

## 절차
1. 카카오로 로그인 → Supabase 가 `auth.uid()` 를 발급 (기존 이름·번호와 무관한 새 ID).
2. 로그인 후 "기존 기록 가져오기" 화면에서 사용자가 직접 확인:
   - 가져올 경기 목록 표시 (날짜·구장·참가자 이름)
   - 본인 기록이라는 확인 체크 + 동의 문구
   - 전화번호는 가져오지 않는다.
3. 확인된 기록만 서버에 저장, 각 기록에 `imported_from = 'device'`, 가져온 사람 ID, 시각을 남긴다.
4. 다른 사람이 같은 이름으로 주장한 기록은 가져오지 않는다 (모임장 확인 필요).
5. 되돌리기: 가져온 기록은 사용자가 삭제할 수 있다.

## 아직 없는 것
- 기존 이름·번호 데이터의 실제 이전 코드 (정책만 정의)
- 카카오 앱 등록과 리다이렉트 주소 설정 (소유자 작업)
