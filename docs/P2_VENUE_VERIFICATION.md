# P2 구장 검증 기록

기준일: 2026-10-27. 근거는 공식 기관 페이지(부산시 낙동강관리본부 등)를 직접 열어 확인한 것만 "검증"으로 표시한다.
언론 기사·개인 블로그·공공데이터 목록만 있는 항목은 "미검증"이다. 확인되지 않은 값은 임의로 채우지 않았다.

## 기존 자료의 문제
- 기존 설정 파일의 좌표, 요금, 전화번호는 출처가 없었다. 이번에 확인한 두 곳 외에는 검증되지 않았다.
- 주소가 실제와 다른 항목이 있었다 (#5).
- 따라서 기존 설정 파일의 값은 사용하지 않는다.

## 다음 단계
- 미검색 항목(14~20)과 재확인 항목(10·12)은 지자체 공식 페이지를 직접 열어 검증한다.
- 지자체 공식 페이지가 없는 곳은 관리자 등록 방식(출처 URL 필수)으로 추가한다.
- 공공데이터포털 파크골프장 목록은 기관 제공 데이터이므로, 이용 약관을 확인한 뒤 가져올지 결정이 필요하다.
