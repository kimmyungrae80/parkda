# PARKDA 2.0 디자인 시스템 (2026-10)

적용 파일: `index.html` 의 `<style>` 끝부분 "PARKDA 2.0 디자인 시스템" 블록과 홈·하단 메뉴 마크업.
토스 앱의 레이아웃 원칙만 참고했고, 로고·아이콘·화면은 복제하지 않았다. 기능 규칙과 데이터 구조는 바꾸지 않았다.

## 명세와 다르게 정한 것 (이유)
- 보조 텍스트 #667085 → **#596275**: #667085 는 연두 배경 위에서 4.39:1 로 AA(4.5:1) 미달.
- 입력창 테두리 #E5E8EB → **#8A93A3**: #E5E8EB 는 흰 배경 1.23:1 이라 입력창 경계가 보이지 않음 (WCAG 1.4.11 3:1 미달).
- 글씨용 강조색: 연두 배경 위에서 #16845B 는 4.13:1 로 미달 → 글씨는 **#0F6A47**, 버튼 배경은 명세의 #16845B 유지.
- Pretendard: 허용된 글꼴 출처(Google Fonts)에 없어 **Noto Sans KR** 유지.

## 적용한 규칙
- 본문 17px, 보조 설명 14px 이상 (인라인 11~13px 는 14px 로 강제), 제목 19~28px.
- 주요 버튼 52~56px, 터치 목표 44px 이상, 체크박스 24px 이상 (라벨이 함께 44px 이상 클릭 영역 제공).
- 카드 반경 18~20px, 그림자 제거, 이모지 제거(마크업) → 선 아이콘 SVG 스프라이트 (`#i-*` 심볼).
- 하단 메뉴 5개: 홈 / 구장 / 모임 / 경기 / MY. 선택 상태는 색 + 굵은 글씨 + 상단 막대로 구분.
- 홈: 상단(로고·지역 선택·알림), 통합검색, 핵심 서비스 4개, 내 주변 구장·모집 중인 모임·더 알아보기(대회·영상·맛집·Club Pro·동호회).
- 알림 버튼은 현재 알림 기능이 없어 MY 화면의 "아직 알림이 없어요" 안내로 연결.

## 아직 하지 않은 것 (정직한 목록)
- 브라우저 확대(200%)는 뷰포트 195px 로 근사했다. 실제 브라우저 확대 설정으로는 확인하지 않았다.
- 스크린샷 육안 검토는 홈과 주요 화면만 했다. 기존 경기관리 화면(조편성·점수·결과)의 세부 배치는 아직 검토하지 않았다.
- JavaScript 가 만드는 버튼 문구의 이모지(예: 경기 목록의 점수 버튼, 결과 화면, 토스트 일부)는 남아 있다. 토스트는 제거했다.
- 전체 WCAG 자동 검사(axe 등)는 실행하지 않았다. 여기 기록된 점검은 직접 만든 스크립트의 항목만이다.
- 기존 경기관리 화면(`pg-create`, `pg-groups`, `pg-score`, `pg-result`)은 색 토큰만 바꿨고 레이아웃은 그대로다.

## 최종 개선 (2026-10-29)

**점수 입력 화면** (`renderScoreFocus`, `bumpScore`, `autoSaveNow`)
- 현재 홀 번호를 48px로, 참가자 이름을 22px로 표시. 이전·다음 홀 버튼으로 이동.
- 타수는 60px 숫자, 파 대비는 글로 표시("파보다 1 적어요"). 색으로만 구분하지 않음.
- +/− 버튼 68px. 입력창에 직접 적는 방식도 그대로 유지 (잘못 입력한 값은 입력창에서 정정).
- 자동 저장 상태 표시: "입력 중… → 저장 중… → 자동 저장됨 · HH:MM" 또는 실패 안내.
- 중단 또는 확정된 경기는 +/− 버튼을 비활성화하고 이유를 문장으로 표시. 기존 중단·재개·결과 확정 기능과 연결됨.
- 기존 데이터 구조(`m.sd`, `scoreLog`, `final`)는 바꾸지 않음. 변경 이력은 기존 `logScoreDiffs` 를 그대로 사용.

**관리자 화면** (`?dev=1` 에서만 열림)
- 주황색 데모 배너로 실제 운영 권한이 없음을 표시. 요약 카드 4개 (동호회, 승인 회원, 검토 필요 신고, 구장 제보).
- 구장 자료 상태는 내부 코드 대신 "공식 자료로 확인 N곳"처럼 읽기 쉬운 문장으로 표시.

**글꼴**
- Pretendard 400·700·800 을 `fonts/` 에 자체 호스팅 (SIL OFL, `fonts/LICENSE.txt`). 로컬 설치본이 있으면 먼저 사용.
- 실패 시 글꼴 스택의 Noto Sans KR → system-ui 순서로 대체. 브라우저에서 세 가지 모두 로드 확인.

**이모지**
- 마크업과 JavaScript 문자열에서 이모지를 제거. 단, 기능 기호 ★ ☆ ✕ ⚠ 는 유지 (즐겨찾기 버튼이 ★/☆ 를 사용하며 테스트가 이를 확인).
- 결과적으로 생긴 회귀 (즐겨찾기 별이 사라짐)는 P3 테스트가 잡아내어 복구함.
