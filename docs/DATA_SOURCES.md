## 3. 주소 기반 자동 지오코딩 (좌표만)

- 서비스: OpenStreetMap Nominatim (https://nominatim.openstreetmap.org)
- 라이선스: ODbL 1.0 · 표시 의무: © OpenStreetMap contributors (화면에 표시함)
- 용도: 좌표가 없는 공식 구장의 주소를 좌표로 바꿈. 같은 시도 안에서 찾은 결과만 사용. 실제 위치와 차이가 있을 수 있음을 화면에 표시.

## 4. 지도 타일·라이브러리

- Leaflet 1.9.4 (cdnjs, BSD-2-Clause), 지도 타일: OpenStreetMap (© OpenStreetMap contributors)

## 5. 유튜브 (YouTube Data API v3)

- 서버 함수 `api/youtube.js` 가 호출하고 6시간 캐시. 키는 환경변수에만 있음. 검색 결과 표시 시 채널·제목·링크 제공 (YouTube 서비스 약관 준수).

## 6. 카카오 로컬 API (음식점·카페·주소 검색)

- 서버 함수 `api/food.js`, `api/geocode.js` 가 호출. 키는 환경변수 `KAKAO_REST_KEY`. 결과는 캐시 (24시간·30일). 광고·제휴 구분 정보는 제공되지 않음.

## 7. 저장소 Excel 자료 (parkda.v2) — 공개하지 않음

- 출처: https://github.com/kimmyungrae80/parkda.v2 (`park_data.xlsx`, `경기장_정보.xlsx`, 같은 내용 383행)
- **라이선스 파일이 없어 재이용 조건을 확인할 수 없습니다.** 따라서 이 자료의 이름·주소·좌표는 공개 목록에 넣지 않았습니다.
- 용도: 내부 검토 후보 목록 생성만 (`data/processed/`, 저장소에서 제외). 공식 출처가 확인되면 그때 공개합니다.

## 8. 이번에 제외한 자료

- 사진DB·골프장 내장객·동호회·강좌·스크린골프 관련 자료: 구장 정보가 아니거나 목적이 달라 제외.
- 인증이 필요한 자료(세종시설관리공단 등): 우회하지 않음.
