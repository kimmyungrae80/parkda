# P1 홈페이지 개편 보고서

브랜치: `feature/parkda-2` · 운영 `main`, 운영 사이트, 운영 DB는 변경하지 않음.

## 1. 구현한 것

| 순서 | 메인 항목 | 구현 | 로그인 |
|---|---|---|---|
| 1 | 로고·상단 메뉴 | PARKDA 로고(기존 이미지 유지), 구장·대회·영상·로그인 메뉴 | 불필요 |
| 2 | 통합검색·지역 선택 | 지역 17곳 + 검색어 → 구장 검색으로 이동 | 불필요 |
| 3 | 전국 파크골프장 찾기 | 카카오 지도 키워드 검색(최대 15곳), 지도 보기, 주변 맛집 | 불필요 |
| 4 | 함께 칠 사람 찾기 | 기존 파트너 화면 연결 | **필요** (🔒 표시) |
| 5 | 전국 파크골프 대회 정보 | 대회·뉴스 목록(기존 뉴스 피드), 주최 측 공지 확인 안내 | 불필요 |
| 6 | 자동 조편성 및 경기관리 | 경기관리 허브 → 새 경기, 경기 목록, 랭킹, 게임코드 참가 | **필요** |
| 7 | 파크골프 유튜브 | 대회·레슨·장비 탭, 유튜브 검색 결과 | 불필요 |
| 8 | 구장 주변 맛집 | 선택한 구장 반경 1km 음식점 (카카오 FD6) | 불필요 |
| 9 | Club Pro 소개 | 소개 + "준비 중" 안내. 결제·개인정보 저장 없음 | 불필요 |

- 비회원 첫 화면은 홈이다. 기존에는 로그인 화면이 먼저 나왔다.
- 홈 진입 시 뉴스·영상·맛집 API를 자동 호출하지 않는다 (해당 페이지에서만 호출).
- 회원 영역(내 KPI, 랭킹, 로그아웃)은 로그인 후에만 보인다.

## 2. 기존 기능 보호

- 자동 조편성, 점수 입력, 게임코드 참가, 정산, 결과 공유 코드는 변경하지 않았다.
- 예외적으로 고친 것: 점수 입력에서 파(par)와 같은 점수를 넣을 때 발생하던 JavaScript 오류 (빈 클래스 토큰 추가).
- 관리자 "전체 삭제"는 차단했다. 되돌릴 수 없고 현재 사용자 목록을 비우는 기능이라서다. 대체 경로는 경기별 삭제(`adminDelMatch`)다.
- 기존 링크 `?game=CODE` 호환 확인 (재방문자 자동 참가).
- 기존 localStorage 데이터 키(`pd_matches`, `pd_match_<코드>`, `pd_user`)를 그대로 사용한다.

## 3. 보안·개인정보

- 서비스워커: 같은 출처의 GET 정적 파일만 캐시. 외부 API(Supabase·YouTube·카카오·뉴스 프록시)와 POST는 캐시하지 않음. 이전 버전 캐시(`parkda-v1`)는 활성화 시 삭제.
- 외부 콘텐츠: 구장·맛집·유튜브·뉴스 제목 등은 이스케이프, 링크는 http(s)만 허용, 유튜브 ID는 형식 검증.
- Club Pro 알림 신청: 개인정보(전화번호)를 저장하지 않고 준비 중 안내만 표시.
- 미리보기 모드: `?local=1`을 붙이면 Supabase를 호출하지 않는다 (운영 DB 보호).
- 관리자 인증과 동호회 권한은 신규 화면에 쓰지 않았다.

## 4. 접근성 (자동 검사 범위만)

- 모든 버튼·링크·입력에 접근 가능한 이름이 있는지 DOM 전체를 점검 (라벨 연결·aria-label), `html lang="ko"`.
- 큰 글자(17px 기본, 제목 최대 48px), 버튼 최소 높이 48–56px, 포커스 표시.
- **미실행**: 명암비 측정(WCAG 2.2 AA), axe 등 전용 도구 검사, 스크린리더 실사용 테스트.

## 6. 미완료·한계

- 구장 목록은 카카오 키워드 검색 결과다. 전국 구장 DB가 없으므로 "전국" 완전성은 보장하지 않는다. 페이지네이션 없음 (최대 15곳).
- 대회 정보는 뉴스 피드다. 대회 일정·신청을 구조화한 데이터가 없다.
- 뉴스는 제3자 CORS 프록시(`api.allorigins.win`)를 거친다. 검색어가 제3자에게 전달되므로 교체가 필요하다.
- 유튜브 API 키가 클라이언트에 있다. 서버 프록시와 쿼터 관리가 필요하다.
- 카카오 키는 JS 키만 사용 (REST 키는 신규 코드에 쓰지 않음). 기존 REST 키 노출은 P0 보고서 대로 재발급 필요.
- Club Pro 결제·알림 저장은 미구현 (RLS 검증 후 진행).
- 관리자 비밀번호·권한은 여전히 브라우저 기반 (서버 인증 전환 필요).
- 경기관리 화면(조편성·점수 등)의 디자인은 아직 기존 그대로다. 새 디자인 적용은 P4 범위.
- 태블릿(768px)은 레이아웃만 확인, 시각 검토는 하지 않았다.
- 실제 카카오·유튜브 응답으로 한 번도 테스트하지 않았다 (스텁 사용).

## 7. 미리보기 실행 방법

```bash
cd ~/Downloads/parkda
git switch feature/parkda-2
python3 -m http.server 8000
# 브라우저: http://127.0.0.1:8000/index.html?local=1
```

- `?local=1`을 빼면 **운영 Supabase 주소로 연결**되어 실제 데이터를 읽고 쓸 수 있다. 미리보기에서는 빼지 않는다.
- 테스트 실행: `python3 tests/e2e/test_regression.py`, `python3 tests/e2e/test_p1_home.py`, `node tests/unit/helpers_test.js index.html`, `node tests/unit/sw_cache_test.js sw.js`
